# セキュリティチェック（20項目）

- 対象：ポートフォリオサイト（`public/` の HTML・CSS・JavaScript・画像の静的サイト）と、問い合わせフォームの受け口（`gas/コード.gs`、Google Apps Script）
- 実施日：2026-11-24（2026-11-25 に作品 04〜06 と問い合わせフォームを足して見直し）
- 前提：ログイン・データベース・アップロード・AI機能はない。サイトは Cloudflare Pages がファイルを配るだけ。問い合わせは Apps Script（自分として実行・だれでも送れる）が受け取り、スプレッドシートに記録して自分の Gmail に通知する

| 番号 | 項目 | 結果 | 根拠 | 直し方・メモ |
| --- | --- | --- | --- | --- |
| 1 | コードに APIキー・パスワードがない | 〇 | `public/`・`gas/` の全ファイルを検索。鍵・パスワードなし。通知の送り先のメールアドレスもコードに書かず、`Session.getEffectiveUser()` で自分を使う | ― |

## あわせて確かめたこと（公開サイトとして）

| 項目 | 結果 | 根拠 |
| --- | --- | --- |
| 実名・メールアドレス・住所が載っていない | 〇 | 表示名は「れおん」だけ。連絡先はクラウドワークスのプロフィールと問い合わせフォーム。通知を受け取るメールアドレスはサイトにも GitHub にも出ない |
| 個人情報の取り扱い | 〇 | `privacy.html` に、集める情報・使う目的・保管（1 年で削除）・第三者に渡さない・開示などの依頼を記載。同意のチェックがないと確認画面に進めず、サーバーでも同意を確かめる。アクセス解析・Cookie は使っていない |
| 画面写真に個人の情報がない | 〇 | 写真 23 枚（共有用の og.jpg を含めて 24 枚）を目で確認。会社名・人名・メール・病院・お薬・金額はすべて見本の架空データ（example.com・見本区など）。ふたり家計簿は本番ではなく、メモリー上の別の環境に架空のデータを入れて撮影。PC のフォルダの場所（ユーザー名）・住んでいる地域は写っていない |
| 画像に撮影情報（EXIF）がない | 〇 | 画面を撮った PNG から WebP に書き出したもので、撮影情報は入っていない |
| 外部リンクの安全 | 〇 | `target="_blank"` には `rel="noopener noreferrer"` |
| 他のサイトの枠に入れられない（クリックジャッキング） | 〇 | `_headers` の `X-Frame-Options: DENY`・`frame-ancestors 'none'` |
