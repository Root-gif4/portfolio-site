# 問い合わせフォームの設置（PC で 1 回だけ・10 分ほど）

サイトの問い合わせフォームから送られた内容を、Google の Apps Script が受け取り、**このスクリプトを作った Google アカウントの Gmail** に通知します。あわせてスプレッドシートにも記録します。メールアドレスはサイトにも GitHub にも書きません。

## 1. スプレッドシートと Apps Script を作る

1. 通知を受け取りたい Google アカウントでログインして、PC のブラウザで `sheets.new` を開きます
2. 左上の名前を「ポートフォリオ 問い合わせ」に変えます
3. メニューの **拡張機能 → Apps Script** を開きます
4. 最初からある `コード.gs` の中身をすべて消して、このフォルダの `gas/コード.gs` の中身を貼り付け、💾 で保存します

## 2. 準備を実行して、許可する

1. 上の関数の選択で **setup** を選び、「実行」を押します
2. 「承認が必要です」→ 自分のアカウントを選ぶ →「Google はこのアプリを確認していません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」
   - 自分で作ったプログラムなので必ず出る画面です。使うのは、このスプレッドシートと自分の Gmail の送信だけです
3. 下の実行ログに「準備ができました。通知の送り先：（自分のアドレス）」と出れば OK です。スプレッドシートに「問い合わせ」のシートができます
4. 関数の選択で **testMail** を選んで「実行」し、Gmail に「問い合わせフォームのテスト」が届くか確かめます

## 3. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ**。歯車から種類を **ウェブアプリ** にします
2. **次のユーザーとして実行：自分**、**アクセスできるユーザー：全員** にします
   - 「全員」にしないと、サイトを見た人が送れません。全員が使えるのは「送る」ことだけで、シートやメールは見えません
3. **デプロイ** を押すと `https://script.google.com/macros/s/…/exec` というアドレスが出ます。これをコピーします

## 4. サイトにつなぐ

`public/index.html` の次の部分の `data-endpoint=""` に、コピーしたアドレスを入れます（Claude に渡してもらえれば入れます）。

```html
<form id="inquiryForm" class="iq-form" data-endpoint="https://script.google.com/macros/s/…/exec" novalidate>
```

空のままのあいだは、フォームは「準備中」と出て使えません。入れたら `public` を Cloudflare Pages にアップロードし、公開版から自分で 1 回送ってみて、Gmail に届くか確かめます。

## 直したいとき

- Apps Script を直したら **デプロイ → デプロイを管理 → ✏️ → バージョン：新バージョン → デプロイ**（アドレスは変わりません）
- 通知の送り先を変えたいときは、そのアカウントで 1 からやり直します（送り先は「スクリプトを作った人」になるため）
- いたずらの送信が多いときは、`LIMIT_PER_HOUR`（1 時間の上限、今は 20 件）を小さくします

## 届いたお問い合わせの扱い

- メールにそのまま返信すると、お問い合わせの方に届きます（返信先をお客様のアドレスにしています）
- [個人情報の取り扱いについて](../public/privacy.html) に「最後のやりとりから 1 年で削除」と書いたので、シートの古い行と Gmail の古いメールは 1 年ごとに消してください
- 通知を受け取る Google アカウントは、二段階認証をオンにしておいてください（個人情報の取り扱いのページにそう書いています）
