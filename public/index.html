Portfolio 01 ・ デスクトップアプリ

業務データ処理ツール

CSV の整形・検証・照合・集計を自動化

ネットショップの受注 CSV と決済サービスの入金 CSV を例に、表記ゆれを直し、誤りや重複を行番号つきで一覧にし、 2 つの CSV を突き合わせて「未入金」「金額違い」「注文のない入金」を見つけ、月別・商品別に集計します。

こんなお困りごとに
毎月の CSV を Excel で手作業で直している／入金の消し込みに時間がかかる／データの間違いに後から気づく

工夫した点

  • 設定ファイルで業務を切り替え：列やチェックの決まりを JSON に書くので、ほかの CSV にもそのまま使えます
  • 元の CSV の行番号で報告：空行や改行が入っていても、元のファイルで探せる番号を出します
  • 勝手に消さない：直せない値は残してエラーにし、直した内容は記録に残します
  • Excel で開いても安全：文字化けしない形式で出力し、数式が勝手に動かない対策も入れました

Portfolio 02 ・ Web アプリ

在庫管理システム

入出庫を記録するだけで、在庫が自動でそろう

小さなお店や社内の備品管理を想定した在庫管理です。入庫・出庫を記録すると在庫数と在庫金額が自動で計算され、 在庫切れや発注が必要な商品をダッシュボードでお知らせします。

こんなお困りごとに
Excel の在庫数がいつの間にかずれる／間違えて直したら履歴が分からなくなった／発注のタイミングを逃す

工夫した点

  • 在庫数は保存せず、記録から計算：数字を二重に持たないので、ずれが起きません
  • 在庫がマイナスにならない：過去の日付で出庫しても、その後のどの日も足りるかを確かめます
  • 取消は「逆向きの記録」を足す：確定した記録は消さず、同じ取引は 1 回しか取り消せません
  • データベースでも守る：制約と書き込みの順番待ちで、同時に操作しても数字が崩れません

Portfolio 03 ・ Web システム

顧客・案件管理システム（CRM）

権限つきで、チームの商談とタスクを一元管理

小さな営業チームを想定した顧客管理です。顧客・案件・タスクを一か所で管理し、ダッシュボードで 「期限切れのタスク」「今月締める案件」がひと目で分かります。3 段階の権限と操作履歴つきです。

こんなお困りごとに
顧客情報が人ごとの Excel に散らばっている／だれが何を進めているか見えない／期限の抜けが起きる

工夫した点

  • 権限の決まりを 1 か所に集約：URL の番号を書き換えても、他人のデータは変更できません（テストで確認）
  • 同時に編集しても上書きしない：先に保存された内容を消さない仕組み（楽観的ロック）
  • だれが・いつ・何を変えたか：操作履歴に変更の前後を残します
  • 安全なログイン：パスワードは復元できない形で保存し、続けて失敗するとロックします

Portfolio 04 ・ スマホ用 Web アプリ

通院ノート

診察で伝えたいことを整理し、お薬と体調を記録

病院に行く前に伝えたいことをまとめ、診察室では先生に見せやすい大きな文字の画面に切り替えられます。 お薬の服薬チェック、体調のつぶやき、受診の記録、病院の情報もひとつに。データはスマホの中だけに保存します。

こんなお困りごとに
診察で聞きたいことを忘れる／お薬をいつまで飲むのか分からなくなる／体調の変化をうまく伝えられない

工夫した点

  • お金をかけず、データを外に出さない：サーバーも有料の API も使わず、病院の情報は Google マップからコピーして貼るだけで振り分け
  • 診察室で使いやすい：先生に見せる画面だけは白地・大きな文字。伝えたものはその場で印をつけられます
  • お薬の期間を自動で計算：飲み始めと処方された数から飲み終わりを出し、同じお薬はまとめて続けられます
  • 見本データで試せる：見本のモードは本物のデータを読みも書きもしません

Portfolio 05 ・ Web システム（自宅サーバー）

ふたり家計簿

ふたりの共同生活費を、スマホからすぐ記録・共有

2 人で暮らす家の家賃・食費・光熱費などを、それぞれのスマホから登録して共有する家計簿です。 月別・カテゴリ別の集計、予算と実績の比較、レシート画像の保存ができます。クラウドの有料サービスは使わず、自宅の PC をサーバーにしました。

こんなお困りごとに
共有の出費をどちらかがまとめて記録するのが大変／レシートがたまる／今月あといくら使えるか分からない

工夫した点

  • ログインなしでも安全に：Tailscale が付ける利用者名をサーバーの許可リストと照合。偽の名前や PC の外からの接続が届かないことを実際に確認
  • データを外に出さない構成：DB と API は外への出口のない内部ネットワークに置き、入口は 1 つだけ
  • 止まっても戻せる：毎日のバックアップ、空き容量の確認、失敗時の通知、定期的な復元テストまで自動化
  • 使い方に合わせて削る：共有の口座で払うので「誰が払ったか」「精算」は作らず、入力を速く

Portfolio 06 ・ Google スプレッドシート＋Apps Script

確定申告ノート

帳簿・請求書・決算書を、スプレッドシートだけで

個人事業・副業の帳簿づけ、請求書・見積書の作成、年末の決算書の数字までを 1 つにまとめた Web アプリです。 会計ソフトの月額料金をかけず、Google スプレッドシートと Apps Script だけで動き、スマホと PC で同じ帳簿を使えます。

こんなお困りごとに
会計ソフトの月額が負担／請求書と帳簿を別々に入れている／簿記の用語が分からず手が止まる

工夫した点

  • 簿記を知らなくても使える：質問に答えるだけで、借方・貸方の仕訳を画面側で組み立てます
  • 請求書と帳簿がつながる：送付・入金に合わせて売上と回収を自動で記録。提案書 → 見積書 → 納品書 → 請求書 と写して作れます
  • Google なしでも確かめられる：計算は画面、保存はサーバーに分け、見本用のしかけで画面だけを動かせます
  • 本人だけが使える：ウェブアプリは「自分だけ」。シートに書く値は数式として動かないようにしています

Process

進め方

6 つの作品も、すべてこの流れで作りました。

  1. ヒアリング今の業務の流れと、困っていることをうかがいます
  2. 要件定義・設計作るものと画面・データの形を資料にして、確認していただきます
  3. 開発・自動テスト決まりごとはテストで確かめながら作ります
  4. セキュリティチェック20 項目を確認し、結果を表でお渡しします
  5. 納品・使い方の説明操作マニュアルつきでお渡しし、使い始めまでお手伝いします

開発には AI（Claude Code）も活用し、設計・テスト・資料づくりを早く・丁寧に進めています。
