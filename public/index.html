Portfolio 01 ・ デスクトップアプリ

業務データ処理ツール

CSV の整形・検証・照合・集計を自動化

ネットショップの受注 CSV と決済サービスの入金 CSV を例に、表記ゆれを直し、誤りや重複を行番号つきで一覧にし、 2 つの CSV を突き合わせて「未入金」「金額違い」「注文のない入金」を見つけ、月別・商品別に集計します。

こんなお困りごとに
毎月の CSV を Excel で手作業で直している／入金の消し込みに時間がかかる／データの間違いに後から気づく

工夫した点

  • 設定ファイルで業務を切り替え：列やチェックの決まりを JSON に書くので、ほかの CSV にもそのまま使えます
  • 元の CSV の行番号で報告：空行や改行が入っていても、元のファイルで探せる番号を出します
  • 勝手に消さない：直せない値は残してエラーにし、直した内容は記録に残します
  • Excel で開いても安全：文字化けしない形式で出力し、数式が勝手に動かない対策も入れました

Portfolio 02 ・ Web アプリ

在庫管理システム

入出庫を記録するだけで、在庫が自動でそろう

小さなお店や社内の備品管理を想定した在庫管理です。入庫・出庫を記録すると在庫数と在庫金額が自動で計算され、 在庫切れや発注が必要な商品をダッシュボードでお知らせします。

こんなお困りごとに
Excel の在庫数がいつの間にかずれる／間違えて直したら履歴が分からなくなった／発注のタイミングを逃す

工夫した点

  • 在庫数は保存せず、記録から計算：数字を二重に持たないので、ずれが起きません
  • 在庫がマイナスにならない：過去の日付で出庫しても、その後のどの日も足りるかを確かめます
  • 取消は「逆向きの記録」を足す：確定した記録は消さず、同じ取引は 1 回しか取り消せません
  • データベースでも守る：制約と書き込みの順番待ちで、同時に操作しても数字が崩れません

Portfolio 03 ・ Web システム

顧客・案件管理システム（CRM）

権限つきで、チームの商談とタスクを一元管理

小さな営業チームを想定した顧客管理です。顧客・案件・タスクを一か所で管理し、ダッシュボードで 「期限切れのタスク」「今月締める案件」がひと目で分かります。3 段階の権限と操作履歴つきです。

こんなお困りごとに
顧客情報が人ごとの Excel に散らばっている／だれが何を進めているか見えない／期限の抜けが起きる

工夫した点

  • 権限の決まりを 1 か所に集約：URL の番号を書き換えても、他人のデータは変更できません（テストで確認）
  • 同時に編集しても上書きしない：先に保存された内容を消さない仕組み（楽観的ロック）
  • だれが・いつ・何を変えたか：操作履歴に変更の前後を残します
  • 安全なログイン：パスワードは復元できない形で保存し、続けて失敗するとロックします

Process

進め方

3 つの作品も、すべてこの流れで作りました。

  1. ヒアリング今の業務の流れと、困っていることをうかがいます
  2. 要件定義・設計作るものと画面・データの形を資料にして、確認していただきます
  3. 開発・自動テスト決まりごとはテストで確かめながら作ります
  4. セキュリティチェック20 項目を確認し、結果を表でお渡しします
  5. 納品・使い方の説明操作マニュアルつきでお渡しし、使い始めまでお手伝いします

開発には AI（Claude Code）も活用し、設計・テスト・資料づくりを早く・丁寧に進めています。
